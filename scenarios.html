Failed Delivery — 2nd Attempt
Trigger: Order appears in CS · Carrier Follow-Up with tag failed-2
failed-2
Owner
CS (Raises) / Manager (Owns)
Priority
🔴 Immediate
📋 Metafields to Check
custom.delivery_detailsConfirm reason for 2nd failed attempt
📋 Step-by-Step
1
Open CS · Carrier Follow-Up tab — prioritize failed-2 orders first.
افتحي تاب CS · Carrier Follow-Up — خلي failed-2 الأول
2
Open the order and review custom.delivery_details.
افتحي الأوردر وراجعي custom.delivery_details
3
Verify customer received automated SMS/email. Contact customer if case is sensitive.
تأكدي إن العميل وصله SMS/email — لو sensitive كلميه
4
Contact Bosta and obtain a reference number.
كلمي Bosta وجيبي reference number
5
Post in #bosta-escalations Slack using exact format: #order | issue | bosta-ref | screenshot
ابعتي في #bosta-escalations بالـ format ده بالظبط
6
Add escalated tag in Shopify ONLY AFTER the Slack post exists.
حطي تاج escalated في Shopify بس بعد الـ Slack post
7
Add a Shopify Note documenting action + Bosta reference number.
أضيفي Note في Shopify بالإجراء + الـ reference
❌ Do NOT
✗ Manually remove the failed-2 tag — the worker clears it.
✗ Add escalated tag without posting in Slack first — invalid escalation.
✗ Open a second Slack thread for the same order — reply in existing one.
⚡ When to Escalate
Immediate escalation to Bosta upon seeing the tag. If Bosta is silent for 12 hours, worker adds escalated-followup — Manager must re-ping.
✅ Definition of Done
Bosta contacted + Slack post exists + escalated tag applied + Shopify Note contains reference.
📝 Example Note
[CS 28/06] Escalated to Bosta — ref 7506992329 — posted in #bosta-escalations.

Tag rules, metafields guide, saved views, and the 4-Point Gate.
🔒
The 4-Point Gate
Trigger: You are about to remove any tag in Shopify
All Teams
⚠️
You MUST pass all 4 questions mentally before clicking X on any tag.
🔒 The 4 Questions
1
Is the actual problem resolved? Not just quiet — actually resolved.
المشكلة اتحلت فعلاً؟ مش بس هدأت
2
Is this a human-clear tag? Only: pending-refund, exchange-returned, return-failed. All others are auto-cleared by worker.
ده تاج بشري؟ بس: pending-refund, exchange-returned, return-failed
3
Did you add a Note? Must contain: What happened + what you did + date + reference.
أضفتي نوت؟ لازم يحتوي: إيه حصل + إيه اللي عملتيه + تاريخ + reference
4
If escalated — does Slack proof exist? No matching Slack post = incomplete/invalid escalation.
لو escalated — فيه Slack post؟ من غيره الـ escalation باطل
❌ Do NOT
✗ Manually remove worker-managed tags: on-hold, failed-2, escalated, card-risk.
✗ Remove third-party tags: bosta_fxf_* or UpPromote_order.
✅ Definition of Done
Tag only removed if it is a finance manual tag, and a stamped Note exists.

Metafields Guide
Trigger: You need more context on why an order is tagged
All Teams
📋 The 4 Key Fields
Navigate to Order → Scroll to Metafields section
custom.last_bosta_updateTimestamp of last Bosta movement. The SLA clock — tells you if shipment is moving or stuck.
custom.bosta_reasonShort reason for exception (e.g. wrong phone). Blank on healthy orders = normal.
custom.delivery_details⭐ Most important for delivery. Full forward line: Status · Reason · Attempts · Since · City.
custom.return_detailsFor returns investigation. Full return line: Return status · Reason · AWB · Date.
❌ Do NOT
✗ Assume blank bosta_reason is a bug if order is delivering normally.
✅ Definition of Done
Operator successfully locates and reads metafields to understand context BEFORE taking any action.
