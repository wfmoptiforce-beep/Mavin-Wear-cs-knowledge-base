4️⃣ Daily Routine — Work Top to Bottom
1
🔴 Fulfillment · Action Required — Fix First
Fix addresses/phones & warehouse blocks. These are stuck on us — highest leverage.
2
🛵 CS · Carrier Follow-Up
Escalate anything at failed-2. Chase SLA breaches & stuck orders. Get a Bosta ref number.
3
💳 Card at Risk
Review failed prepaid orders. Decide: re-ship, refund, or hold. Log decision in Note.
4
💰 Refunds Owed → Returns
Finance: issue refunds, chase failed returns, close exchanges — then remove the tag manually.
5
📝 Log Everything in Order Notes
Every action gets one stamped line in the order Note. See examples below.
5️⃣ How to Write an Order Note
Examples — copy the format exactly:
[CS 28/06] Called customer, corrected address in Bosta, asked for re-attempt.
[CS 28/06] Escalated to Bosta (ref 7506992329) — posted in #bosta-escalations.
[FIN 28/06] Refund issued EGP 426.50 — removing pending-refund.
[OPS 28/06] Cleared warehouse block — order re-queued for dispatch.
6️⃣ Golden Rules
✅
Tag gone = solved
No "-done" tags. Finish the work and the tag disappears. Absence is the signal.
✅
Always write a Note
Every manual action gets one stamped line. The tag is the state — the Note is what you did.
✅
Escalating? Post in Slack first
Post in #bosta-escalations (order # | issue | ref | screenshot), THEN add the escalated tag.
⛔
Don't touch robot tags
Never remove auto tags (bosta_fxf_*, UpPromote, robot-set tags). Only remove finance/return tags after action is done.
⛔
No Slack post = invalid escalation
A tag with no matching Slack post is invalid. The Slack timestamp is the proof.
⛔
Don't refund before confirming return
Check return_details says RETURNED before issuing any refund.
