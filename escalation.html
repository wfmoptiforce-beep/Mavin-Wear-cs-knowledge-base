📋 Step-by-Step Escalation Process
Follow this exact sequence — do not skip or reorder steps
1
Collect Required Details
Order ID, issue type, Bosta reference number (if already obtained).
جمعي: Order ID + نوع المشكلة + Bosta reference number
2
Post in #bosta-escalations Slack — FIRST
Use the exact format below. Do not deviate. Screenshot required.
ابعتي في #bosta-escalations الأول — بالـ format بالظبط
3
Add escalated Tag in Shopify
Only after the Slack post exists and is confirmed. Not before.
بس بعد ما الـ Slack post موجود — مش قبله
4
Add Shopify Note
Document: action taken + Bosta reference + date. Use the format below.
أضيفي نوت: الإجراء + Bosta reference + تاريخ
5
Monitor for 12 Hours
If Bosta doesn't respond in 12h — worker adds escalated-followup — Manager re-pings in same thread.
لو Bosta مش رادة في 12 ساعة — worker يضيف escalated-followup — Manager يتابع في نفس الـ thread
❌ Do NOT
✗ Add escalated tag without a matching Slack post — invalid escalation.
✗ Open a new Slack thread for the same order — reply in existing one.
✗ Manually remove escalated or escalated-followup tags.
✅ Definition of Done
Slack post exists in correct format + escalated tag applied in Shopify + Note stamped with reference.
