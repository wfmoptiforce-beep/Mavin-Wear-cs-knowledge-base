Escalation Protocol & Slack Workflow

Every escalation must have a paper trail. No tag without a Slack post. No Slack post without a reference. Follow the exact format — every time.

كل تصعيد لازم يكون ليه أثر موثق. مفيش تاج من غير Slack post. مفيش Slack post من غير reference. اتبعي الـ format بالظبط — كل مرة.

🚨
Golden Rule: Post in #bosta-escalations FIRST — then add the escalated tag in Shopify. A tag without a Slack post is an invalid escalation.
القاعدة الذهبية: ابعتي في #bosta-escalations الأول — بعدين أضيفي تاج escalated في Shopify. تاج من غير Slack post = تصعيد غير صالح.

الـ tags دي بتشغّل بروتوكول التصعيد فوراً

ℹ️
After escalating:

• Worker auto-adds escalated-followup if Bosta is silent for 12 hours.

• Manager must re-ping Bosta in the same Slack thread.

• Never open a new thread for the same order.
بعد التصعيد:

• الـ Worker بيضيف escalated-followup أوتوماتيك لو Bosta مش رادة في 12 ساعة.

• الـ Manager لازم يتابع في نفس الـ Slack thread.

• لا تفتحي thread جديد لنفس الأوردر.
📋 Step-by-Step Escalation Process خطوات التصعيد بالترتيب
Follow this exact sequence — do not skip or reorder steps
اتبعي التسلسل ده بالظبط — لا تتخطي أو تقدمي خطوة
1
Collect Required Details
اجمعي البيانات المطلوبة
Order ID, issue type, Bosta reference number (if already obtained).
Order ID + نوع المشكلة + Bosta reference number (لو موجود).
2
Post in #bosta-escalations Slack — FIRST
ابعتي في #bosta-escalations الأول
Use the exact format below. Screenshot required.
استخدمي الـ format اللي تحت بالظبط. Screenshot مطلوب.
3
Add escalated Tag in Shopify
أضيفي تاج escalated في Shopify
Only after the Slack post exists and is confirmed. Not before.
بس بعد ما الـ Slack post موجود ومتأكد منه — مش قبله.
4
Add Shopify Note
أضيفي نوت في Shopify
Document: action taken + Bosta reference + date.
وثّقي: الإجراء + Bosta reference + التاريخ.
5
Monitor for 12 Hours
تابعي لمدة 12 ساعة
If no response — worker adds escalated-followup — Manager re-pings in same thread.
لو مفيش رد — الـ Worker يضيف escalated-followup — الـ Manager يتابع في نفس الـ thread.
❌ Do NOT
✗ Add escalated tag without a matching Slack post — invalid escalation. تضيفي تاج escalated من غير Slack post — تصعيد غير صالح.
✗ Open a new Slack thread for the same order — reply in existing one. تفتحي thread جديد لنفس الأوردر — ردي في الموجود.
✗ Manually remove escalated or escalated-followup tags. تشيلي تاج escalated أو escalated-followup يدوياً.
✅ Definition of Done
Slack post exists in correct format + escalated tag applied + Note stamped with reference.
Slack post موجود بالـ format الصح + تاج escalated متحط + نوت موثق بالـ reference.
